# OAuth provider icons that were missing (shellui/admin PR #29)

Scope: providers in identity-service `apps/authapi/provider_catalog.json` (branch `cursor/allauth-oauth-catalog-3e48`, allauth 65.19.5) with `supported: true` and `legacy: false` (97 providers). I compared their `docs_slug` values against `OAUTH_ICON_LOADERS` in `src/assets/oauth-icons/oauthIconManifest.ts` on `cursor/oauth-setup-wizard-c6a4` (83 loaders). **33 shown providers had no bundled icon.** That is the same list as `OAUTH_ICON_FALLBACK_SLUGS`, minus `draugiem`, which the catalog marks `supported: false`.

Collected 2026-09-29. All SVGs were optimised with `svgo 4.1.0` (preset-default, keeping viewBox, `removeDimensions`, multipass). All of them have a square viewBox except three whose original artwork is nearly square: mailcow 395×377, ynab 576×569, doximity 491×505.
`*-dark.svg` / `*-dark.png` = variant for dark themes, following the PR's `{slug}-dark.svg` convention.
`png-as-svg/` = the PNG-only icons wrapped in an SVG `<image>` (base64). The PR loader imports `*.svg?raw`, so these wrappers let those icons plug in unchanged.

**Licensing note:** these are all trademarks. Even when the file is CC0, MIT or public domain, that covers the copyright only. Brand assets taken straight from a company's own site come with no open licence. They are used here only to identify the provider on its sign-in or setup button (nominative use), which is how the rest of the PR's icons are used.

## Suggested manifest flags (for `OAUTH_ICON_META`)

- `invertOnDark` / dark alternates: drip, edmodo, eveonline, exist, frontier, klaviyo and wahoo now ship `-dark.svg` files, so no CSS inversion is needed. Doximity, jupyterhub and questrade also have official dark variants.
- Only PNG exists for agave, authentiq, cilogon, clever, feishu, lemonldap, questrade, trainingpeaks and yahoo. You can use `png-as-svg/<slug>.svg` with the existing `?raw` loader.
